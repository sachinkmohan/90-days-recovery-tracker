# Feedback leaves the device only through the user's mail app

Feedback is a bug report or a feature suggestion the user sends the developer. Send feedback opens the device mail app. The prefilled message contains only an app version and platform line. It must not include the round, relapses, mood, or check-ins, and the app does not learn whether the email was sent.

A form or a server would make bug reports easier to diagnose, and would also mean recovery state can leave the device on the app's behalf. The mail app keeps that handoff in the user's hands. If the device has no mail app, the user can copy the address and the subject. We do not run a backend for this.
